# Estrategia-comercial-de-Andes-Capital-Real-Estate
Construir un dashboard interactivo en Tableau que permita analizar ventas, clientes y propiedades para apoyar decisiones estratégicas.


Empresa inmobiliaria que necesita comprender mejor el desempeño comercial.

La empresa gestiona la venta de diferentes tipos de propiedades a través de distintos canales de venta y segmentos de clientes.

Actualmente, la información existe a nivel transaccional, pero no hay una visión analítica clara del negocio.

💡 **Preguntas del negocio**

El dashboard ayuda a responder preguntas como:

¿Cuál es el ingreso total generado por las ventas de propiedades?

📂 **Dataset del proyecto**

El proyecto utiliza una **tabla de hechos (ventas)** y **tablas dimensionales (clientes y propiedades).**


**Flujo general del proyecto**

1. Limpieza de datos	Validar tipos de datos, nulos y duplicados.	Dataset listo para análisis.
   <head></head>
	 
2. Modelado de datos	Construir esquema estrella.	Modelo analítico correcto.
   <head></head>
	 
3. Crear medidas	Construir métricas comerciales e inteligencia de tiempo.	Insights del negocio.
   <head></head>
	 
4. Diseñar dashboard	Crear páginas de análisis ejecutivo, comercial y cohortes.	Visualización clara.
   <head></head>

5. Resumen ejecutivo	Interpretar resultados y generar recomendaciones.	Insights estratégicos.
